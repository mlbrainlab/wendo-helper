# Wendo Helper

A small companion app for [Wendo](https://wendo-legal.pages.dev), the Android automations app.

Android no longer lets ordinary apps switch Wi‑Fi on or off by themselves. Wendo Helper is built for an older Android
version, which Android still allows to do it. With the helper installed, Wendo's "Turn Wi‑Fi on/off" steps run by
themselves instead of asking for a tap.

- It only listens to Wendo. Other apps can't use it.
- It has no internet access and collects nothing.
- It isn't on Google Play: download the latest APK from [Releases](../../releases/latest) and open it to install.
  Android may warn that it was built for an older version; that is expected.
